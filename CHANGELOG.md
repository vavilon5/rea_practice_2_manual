# Changelog

## 1.1.1

- Новые операции `power` (`^`) и `modulo` (`%`).
- `python -m calculator` без аргументов выводит версию в справке.
- Автоматическое слияние PR из `development`, публикация релизов по тегу.

## 1.1.0

- Базовые операции `add`, `subtract`, `multiply`, `divide`.
- Вычислитель выражений `evaluate` и CLI `python -m calculator`.
- CI на GitHub Actions, автогенерация документации.
