# Руководство пользователя

## Как библиотека

```python
from calculator import add, divide, evaluate

add(2, 3)          # 5
divide(9, 3)       # 3.0
evaluate("6 * 7")  # 42
```

## Из командной строки

```bash
python -m calculator "10 - 4"   # 6
python -m calculator "1 / 0"    # Ошибка: Деление на ноль невозможно (код возврата 1)
```

Поддерживаемые операторы: `+`, `-`, `*`, `/`, `%` (остаток), `^` (степень). Операнды и оператор разделяются пробелами.
